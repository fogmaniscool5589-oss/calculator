# CALC 2.0
A not that simple but still useable and fun calculator program

## Instructions

### How to Use

1. **Run the Program**
   ```bash
   python calculator.py
   ```

2. **Enter Your Numbers**
   - When prompted, enter your first number
   - Then enter your second number

3. **Select an Operation**
   - `+` for addition
   - `-` for subtraction
   - `x` for multiplication
   - `/` for division
   - `**` for exponentiation (power)

4. **View Your Result**
   - The calculator will display your answer

### Example

```
please select first number: 10
please select next number: 5
select + - x / ** for it to work: +
15
```

### Supported Operations

| Operation | Symbol | Example |
|-----------|--------|---------|
| Addition | `+` | 10 + 5 = 15 |
| Subtraction | `-` | 10 - 5 = 5 |
| Multiplication | `x` | 10 x 5 = 50 |
| Division | `/` | 10 / 5 = 2 |
| Exponentiation | `**` | 10 ** 2 = 100 |

### Requirements

- Python 3.x
